Patchbell

내 프로그램의 보안 업데이트를 확인하세요

Patchbell은 등록한 프로그램, 에디터, SDK의 설치 버전에 영향을 주는 공개 보안 공지를 확인하고 데스크톱에서 알림을 보내는 Windows·macOS 앱입니다.

Patchbell 홈페이지 다운로드 GitHub 저장소

Patchbell에서 할 수 있는 일

  • 이 기기에 설치된 앱과 개발 도구를 찾아 등록하거나 직접 버전을 입력할 수 있습니다.
  • npm 프로젝트에서 설치된 의존성을 읽어 추적할 패키지를 고를 수 있습니다.
  • 설치 버전에 영향을 주는 공지가 있으면 알림을 받고 공식 업데이트 안내를 열 수 있습니다.
